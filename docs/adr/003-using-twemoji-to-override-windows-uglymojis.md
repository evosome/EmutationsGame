# ADR-002: Выбор Twemoji для приятных в визуальном плане эмодзи

## Статус
Принято (Accepted)

## Контекст
Мы разрабатываем легковесное клиентское веб-приложение для генерации монстров на основе эмодзи. 
Одно из требований:
* Красивые символы-эмодзи

## Решение
1. Использовать twemoji и заменять unicode-символы эмодзи на SVG от twemoji через action в Svelte

## Рассмотренные альтернативы
* N/A

## Последствия
* **Плюсы**: Приятный визуал и красивые эмодзи
* **Минусы**: Возможные проблемы с перформансом
