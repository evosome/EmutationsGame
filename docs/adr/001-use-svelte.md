# ADR-001: Выбор технологического стека

## Статус
Принято (Accepted)

## Контекст
Мы разрабатываем легковесное клиентское веб-приложение для генерации монстров на основе эмодзи. 
Основные требования:
* Высокая скорость разработки (MVP).
* Минимальный размер бандла для быстрой загрузки на слабых ноутбуках.
* Сборка в одиночный HTML.

## Решение
1. Использовать фреймворк **Svelte** (без SvelteKit)

## Рассмотренные альтернативы
* **React**: Отклонено. Дает избыточный оверхед в виде Virtual DOM и увеличивает размер бандла, что критично для простого MVP. Нет возможности собрать в один небольшой HTML файл.

## Последствия
* **Плюсы (Svelte)**: Декларативный и понятный код. Отсутствие Virtual DOM обеспечивает максимальную производительность на слабых смартфонах. Стили изолированы «из коробки».
