# AGENT

# Доменные сущности

1. Мутантик (Монстрик) -- собранный из изображений эмодзи персонаж. Монстрик состоит из эмодзи:
   1. Шапки (поверх головы)
   2. Головы
   3. Туловища (ниже головы)
   4. Рук (по бокам туловища)
   5. Ног (снизу туловища)
2. Эмодзи -- Символ-пиктограмма, из которого будет состоять мутантик
3. Пул эмодзи -- это взвешенный набор символов-эмодзи, из которого можно получить случайный эмодзи
4. Ген (сид) -- строковое значение (вида `xxx-xxx-xxx-xxx` превращаемое в хеш), которое выдает одного и того же мутантика
5. Барабан -- 7-слотовый барабан, который визуально отражает, какой эмодзи был выбран для данного мутантика. Результат крутки, разумеется, известен заранее.
6. История создания мутантиков -- Список созданных игроком мутантиков. Отображается внешний вид мутантика и ген (сид).

## GDD

### Целевая платформа

Web HTML5

### Механики

1. Игрок может задать ген (сид) мутации монстрика, чтобы получать гарантированно один и тот же результат
2. При задании нового гена (сида) игра крутит барабан из 7 слотов-эмодзи. Если сид был задан, барабан не крутится
3. Игра вычисляет редкость монстрика по весам его эмодзи. Редкости варьируются:
   1. STINKY (вонючий)
   2. POOR (беднейший)
   3. COMMON (непримечательный)
   4. UNCOMMON (необычного вида)
   5. CUTY (милый)
   6. STRANGE (странный)
   7. EPIC (невероятный)
   8. MIND\_BLOWING (умопомрачительный)
   9. LEGENDARY (легендарнейший)
   10. NONEXISTING (невообразимый)
4. Игра вычисляет качество монстрика по весам его эмодзи + небольшая случайность, округляющая результат вверх/вниз. И варьирует качество по:
   1. HAUNTED (из лохмотьев)
   2. BOUGHT (с барахолки)
   3. INTERESTING (с особенностями)
   4. GOLDEN (с позолотой)
   5. BRILLIANT (из драгоценностей)
   6. PERFECT (высшей пробы)
5. Игра подбирает название монстрика по эмодзи его головы
6. Игра склеивает название редкости, имя эмодзи-головы и имени качества. Например: `невероятный клоун высшей пробы`
7. Игра назначает цвет названию предмета по его редкости

## Типы и иерархия компонентов

### Типы

```typescript

enum EmutationRarity {
  STINKY,
  POOR,
  COMMON,
  UNCOMMON,
  CUTY,
  STRANGE,
  EPIC,
  MIND_BLOWING,
  LEGENDARY,
  NONEXISTING,
}

enum EmutationQuality {
  HAUNTED,
  BOUGHT,
  INTERESTING,
  GOLDEN,
  BRILLIANT,
  PERFECT,
}

interface EmutationBodyparts {
  hat?: string;
  head?: string;
  body?: string;
  leftHand?: string;
  rightHand?: string;
  leftLeg?: string;
  rightLeg?: string;
}

interface EmutationMonster {
  gen: string;
  rarity: EmutationRarity;
  quality: EnumtationQuality;
  baseName: string;
  bodyparts: EnumationBodyparts;
}
```

### Описание компонентов

* `MutationHistory` -- список-история генераций монстриков. В каждой карточке генерации указан внешний вид монстрика (через компонент `EmutationCanvas`), его ген. Также в карточке будет кнопка, чтобы скопировать скриншот монстрика в буфер обмена. Список-история ограничен небольшим размером -- всего 6. Это сделанно для того, чтобы у игрока появился азарт -- потерять текущего монстрика и сделать нового в надежде выбить крутого.
* `GenField` -- строковое значение (формата `xxx-xxx-xxx-xxx`), которое представляет собой зерно-хеш для генератора случайных чисел. В момент создания нового монстрика данный сид меняется на случайный и используется для генератора монстрика. У филда должен быть плейсхолдер вида: `XXX-XXX-XXX-XXX`. Валидация через Regex.
* `MutationRoll` -- компнент, который представляет собой 7-слотовый барабан. На этом барабане по очереди вращаются эмодзи, отвечающие за: голову (выбирается самой первой), туловище, руки, ноги, шапку. После рола каждого эмодзи, выбранные эмодзи отображаются на `EmutationCanvas`.
* `MutationCanvas` -- Компонент, на котором отображается результат генерации монстрика. Каждая отдельная часть монстрика (эмодзи) представлена в виде `div` компонента. Стоит отметить, что одна из рук монстрика инвертирована по X через стиль `scale: -1 1` для эстетического вида. Тоже касается и ноги монстрика.
* `MutationWindow` -- собирает воедино MutationCanvas, MutationRoll, GenField и кнопку генерации.
* `MutationCard` -- карточка созданного монстрика. В ней отображается MutationCanvas (как выглядит монстрик), название монстрика (вычислено через поля редкости, качества из EmutationMonster). Также записан ген монстрика, чтобы его можно было воспроизвести.

### Иерархия компонентов

* Content
  * MutationWindow \[component, orchestrate MutationCanvas, MutationRoll, GenField and Button] fill EmutationBodyparts with emojis from MutationRoll
    * mutation\_\_canvas-roll-container
      * MutationCanvas \[component] consumes EmutationBodyparts
      * mutation\_\_info
        * mutation\_\_roll-container
          * MutationRoll \[component, rolls emojis step-by-step, emoji available via signal onEmojiSelected = (emoji: string, rollIdx: number): void] consumes genState
        * mutation\_\_seed-button-container
          * GenField \[component, editable, onChange triggers canvas redraw, not roll] consumes genState
          * Button \[component, onClick signal triggers generation]
  * MutationHistory \[component]
    * MutationCards \[scrollable, container]
      * MutationCard \[component, build name from rarity and quality enums] consumes EmutationMonster
        * info\_\_monster-name \[element] consumes name
        * MutationCanvas \[component] consumes EmutationBodyparts
        * GenField \[component] consumes gen
