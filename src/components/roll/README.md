
## EmutationRoll.svelte

### 1. Стек и Архитектурная роль
- Фреймворк: Svelte 5 (Руны: $state, $derived, $effect).
- Роль: Single Source of Truth (Единый источник правды) и Главный таймер интерфейса. 
- Задача: Управление массивом из 7 дочерних слотов (`Reel.svelte`) и координация их жизненного цикла (Старт -> Запрос данных -> Поочередная остановка).

### 2. Управление состоянием (State Management)
Компонент должен хранить в едином реактивном массиве `$state` конфигурацию всех 7 слотов:
```typescript
interface SlotState {
  id: number;
  delay: number;         // Задержка старта для эффекта "волны"
  targetSymbol: string;  // Символ, который должен выпасть
  isSpinning: boolean;   // Флаг, передаваемый в Reel
  dropChance: number;    // Процент выпадения для MutationCell
}
```
- Общее состояние игры: `isGameActive: boolean` (блокирует кнопку запуска во время кручения).

### 3. Алгоритм Жизненного Цикла Крутки (Timing & Wave Effects)
При вызове функции запуска (клик по кнопке генерировать), оркестратор должен выполнять строго следующий пайплайн:

#### Фаза 1: Запуск («Волна старта»)
- Установить `isGameActive = true`.
- Перебрать массив слотов и выставить каждому `isSpinning = true`.
- Важно: У каждого следующего слота параметр `delay` увеличивается последовательно (например, `index * 150ms`), чтобы барабаны срывались с места один за другим слева направо.

#### Фаза 2: Крутка и ожидание
- Во время ожидания (пусть будет 1 секунда) слоты крутятся в бесконечном цикле (фаза `loop` внутри Reel), генерируя случайные эмодзи.

#### Фаза 3: Остановка («Волна финиша»)
- При получении финального массива из 7 символов от сервера (или мок-данных), запустить поочередную остановку.
- Использовать каскадный таймер: выключать `isSpinning = false` и передавать `targetSymbol` для каждого слота с шагом в `200мс` (первый слот тормозит сразу, второй через 200мс, третий через 400мс и т.д.).
- Как только последний (7-й) слот полностью завершил анимацию и выровнялся, сбросить `isGameActive = false`, разблокировав интерфейс.

### 4. Верстка и Интеграция компонентов
- Компонент должен рендерить флекс-контейнер (`display: flex; gap: Xpx`) с 7 элементами.
- Каждый элемент — это контейнер ячейки (`MutationCell.svelte`), внутрь которого передается процент выпадения (`dropChance`), а внутрь него монтируется `<Reel />` с пропсами `isSpinning`, `targetSymbol` и `delay`.

### 5. Ограничения для ИИ
- ЗАПРЕЩЕНО управлять анимацией пикселей из этого компонента. Оркестратор меняет ТОЛЬКО логические флаги (`isSpinning` и `targetSymbol`).
- Код должен быть защищен от race conditions (повторный клик по кнопке во время кручения должен игнорироваться).

## Компонент Ячейки (Slot.svelte, ранее MutationSlot)
- Роль: Обертка, объединяющая `Reel.svelte` и блок мета-информации.
- Вычисление данных: Использовать руну `$derived` для реактивного получения цены и редкости из утилиты `getSymbolMeta(symbol)`.
- UX-модификатор: Во время фазы `isSpinning === true` блок с мета-информацией (цена, редкость) должен получать CSS-класс `.dimmed` (opacity: 0.3), чтобы текст не отвлекал пользователя во время быстрого вращения. Данные обновляются финальными значениями только в момент полной остановки барабана.

## Требования к компоненту Reel

### 1. Стек и Окружение
- Svelte 5. Использовать ТОЛЬКО руны: $state, $derived, $effect, пропсы через $props()).
- Логика данных: подбор случайных эмодзи должен быть вынесен во внешнюю утилиту 

### 2. Архитектурный паттерн: Virtual Scroll (Object Pooling)
Критически важно для производительности (60 FPS):
- В DOM всегда должно находиться строго фиксированное количество элементов (3 ячейки).
- Направление движения: Сверху вниз.
- Зацикливание: Когда ячейка пересекает нижнюю границу видимости, её координата Y мгновенно сдвигается наверх, а символ перезаписывается новым значением из утилиты.

### 3. Физический движок (Анимация на JS)
Анимация должна управляться строго через цикл `requestAnimationFrame`. Использовать setInterval/setTimeout для движения ЗАПРЕЩЕНО.
Компонент должен проходить через 4 строгих состояния (стейт-машина):
1. `idle`: Скорость = 0. Ожидание сигнала.
2. `accelerating`: Плавное увеличение скорости (`speed += шаг`) до достижения `maxSpeed`.
3. `loop`: Бесконечное вращение на максимальной скорости. В этот момент ячейки зацикливаются и получают случайные эмодзи.
4. `decelerating`: Плавное снижение скорости, переходящее в фазу точного выравнивания (`snapping`), где выигрышная ячейка с `targetSymbol` встает ровно в центр (координата Y = 0).

### 4. Контракт компонента
пропсы:
- `isSpinning: boolean` — триггер старта (true) и команды на остановку (false).
- `targetSymbol: string` — символ, на котором барабан обязан остановиться.
- `delay: number` — задержка старта в мс (для эффекта последовательного запуска).

### 5. Ограничения отрисовки (Performance Rules)
- Смещение ячеек реализовывать строго через `transform: translate3d(0, Y, 0)` для выноса отрисовки на GPU.
- Добавить CSS-свойство `will-change: transform` для элементов ячеек.
- Контейнер-маска должен иметь фиксированную высоту одной ячейки и `overflow: hidden`.
